## 部署 / Deployment

### GitHub Pages 部署

1. 新建 GitHub 仓库，命名为 `your-username.github.io`
2. 将所有文件上传到仓库根目录
3. 进入 Settings → Pages
4. Source 选择 `Deploy from a branch`，Branch 选择 `main`
5. 等待 1-2 分钟，访问 `https://your-username.github.io`
